## 🔧 기술 스택

### 프론트엔드

| 분류             | 기술 스택                  |
| ---------------- | -------------------------- |
| Lang & Framework | TypeScript, React, Next.js |
| Style            | TailwindCSS                |
| Test / Dev Tool  | Storybook, Vitest          |
| Package Manager  | Yarn                       |
| Deploy           | Vercel                     |

### 백엔드

| 분류             | 기술 스택                                    |
| ---------------- | -------------------------------------------- |
| Lang & Framework | Java 17, Spring Boot                         |
| Infra            | AWS EC2, GitHub Actions, Redis, Docker       |
| DB               | H2, MySQL, Flyway, Spring Data JPA           |
| Test             | JUnit5, RestAssured, Mockito, Fixture Monkey |
